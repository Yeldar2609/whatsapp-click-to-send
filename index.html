WhatsApp Click-to-Send

International-ready. Detects country by dialing code, groups your list, and flags numbers missing a code before you send.
Flow per person: Copy message → Open chat → click the message box → Ctrl+V → Enter. Copy-paste keeps emojis intact (pre-filled links corrupt them).
The international trap: a number MUST include its country code, no +. Kazakhstan 7701..., US 1202..., India 9198..., UAE 97150.... A number saved in local format (e.g. Kazakh 8701... or a bare US 202...) can't be auto-fixed and gets flagged no country code. Fix those by hand before sending or the message goes nowhere, or to a stranger.
